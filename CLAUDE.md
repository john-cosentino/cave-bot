# Cave Bot — project instructions

## What this is

A Flask webhook service that powers a GroupMe chat bot with switchable AI
personas. It receives GroupMe callbacks, decides whether to reply, and posts
back through the GroupMe bot API. Persona replies are generated by the
Anthropic API when that is enabled.

## Architecture

```
src/cave_bot/groupme_app.py      Flask routes and reply routing (entry point)
src/cave_bot/personas.py         loads and validates persona JSON
src/cave_bot/persona_registry.py holds loaded personas and which is active
src/cave_bot/ai_reply.py         Anthropic API wrapper
src/cave_bot/authorization.py    admin check by GroupMe user ID
data/personas/profiles/*.json    persona definitions (data, not code)
```

Boundaries worth preserving:

- **Personas are data.** Adding a character means adding a JSON file, not
  editing Python. Keep it that way.
- **The AI client is injected, never constructed inside reply logic.**
  `build_reply()` takes `ai_client` as a parameter. This is what lets the whole
  suite run without network access. Do not move client construction into it.
- **`personas.py` and `authorization.py` import no Flask and no network
  library.** Keep them that way.

## Testing

Tests are standard library `unittest`. pytest is not installed and is not a
dependency — do not assume it.

```
cd ~/git/cave-bot && PYTHONPATH=src .venv/bin/python -m unittest discover -s tests
```

`PYTHONPATH=src` is required: there is no `pyproject.toml`, `setup.py`, or
`conftest.py`, so `cave_bot` is not otherwise importable.

Every change must keep the suite green. Tests must never make real network
calls or real Anthropic API calls — use `unittest.mock`, as the existing tests
do.

## Safety

- This project uses two credentials: a GroupMe bot ID and an Anthropic API key.
  Both come from the environment. Never write either into a file, a test, a
  document, a commit message, or a log line.
- Record environment variable names only, never values.
- Do not post to the real GroupMe API while developing or testing.
